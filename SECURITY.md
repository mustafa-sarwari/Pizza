# Security Policy

## Supported Versions

This project is a simple static website. We aim to keep it secure and up-to-date.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it by:

1. **Do NOT** open a public issue
2. Send an email describing the vulnerability
3. Include steps to reproduce the issue
4. Allow up to 48 hours for an initial response

We take all security reports seriously and will respond promptly.

## Security Best Practices

This project follows these security practices:

- Uses HTTPS for all external resources (CDN links)
- No sensitive data is stored or processed
- Regular updates to dependencies (when applicable)
- Clean, validated HTML and CSS code
