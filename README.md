# 🍕 Pizza Landing Page

A clean, modern pizza landing page built with **HTML5** and **CSS3**. This project demonstrates fundamental web development skills including semantic HTML structure, custom styling, responsive design principles, and modern layout techniques.

> 🎨 Built as part of my web development learning journey to practice webpage layout, design, and styling fundamentals.

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/mustafa-sarwari/Pizza.git
   ```

2. Navigate to the project directory
   ```bash
   cd Pizza
   ```

3. Open `index.html` in your browser
   - Double-click the file, or
   - Use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js
     npx serve .
     ```

4. Visit `http://localhost:8000` (if using a local server)
